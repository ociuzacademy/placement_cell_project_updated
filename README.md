# Student Excel Upload – Required Format

The Excel file must contain the following columns **in this exact order**:

1. Student ID
2. Roll No
3. Reg No
4. Student Name
5. Gender
6. Student Email
7. Student phone
8. Parent phone
9. Address
10. Department
11. Course
12. Batch
13. Year
14. Supply
15. Resume
16. Pancard Number


### Important Notes

* Sudent ID must be unique.
* Department and Course names must match the values available in the system.
* Batch format:2022-2026
* Year 1, 2 , 3, or 4
* Supply numeric value such as 0, 1, 2
* Phone numbers should be entered as 10-digit values and preferably formatted as Text in Excel.
* Resume can be left blank.
* Pancard Number should be the individual PAN number of each student.
* Save the file in .xlsx format.

### Excel Header

Student ID | Roll No | Reg No | Student Name | Gender | Student Email | Student phone | Parent phone | Address | Department | Course | Batch | Year | Supply | Resume | Pancard Number
